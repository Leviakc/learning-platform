# Numbers: Integers and Floats 🔢

<br />

In Python, we use two main types of numbers:

<br />

### 1. Integers (int)
These are whole numbers, either positive or negative, without decimals.
<br />
```python
age = 25
temperature = -5
```

<br />

### 2. Floating-Point Numbers (float)
These are numbers that contain a decimal point.
<br />
```python
price = 19.99
pi = 3.14159
```
<br />
**Note:** Even if a number ends in `.0` (like `5.0`), Python considers it a **float**.

<br />

### 3. Basic Math Operations
Python can be used as a powerful calculator!
<br />
*   `+` (Addition): `5 + 2` is `7`
*   `-` (Subtraction): `5 - 2` is `3`
*   `*` (Multiplication): `5 * 2` is `10`
*   `/` (Division): `5 / 2` is `2.5`
<br />
### 4. Advanced Operators
*   `%` (Modulo): Gives you the **remainder** of a division. `5 % 2` is `1` (because 2 goes into 5 twice, with 1 left over).
*   `**` (Exponentiation): Raises a number to a power. `5 ** 2` is `25` (5 squared).

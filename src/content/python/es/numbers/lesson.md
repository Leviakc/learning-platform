# Números: Enteros y Flotantes 🔢

<br />

En Python, usamos principalmente dos tipos de números:

<br />

### 1. Enteros (int)
Son números completos, ya sean positivos o negativos, sin decimales.
<br />
```python
edad = 25
temperatura = -5
```

<br />

### 2. Números de Punto Flotante (float)
Son números que contienen un punto decimal.
<br />
```python
precio = 19.99
pi = 3.14159
```
<br />
**Nota:** Incluso si un número termina en `.0` (como `5.0`), Python lo considera un **float**.

<br />

### 3. Operaciones Matemáticas Básicas
¡Python puede usarse como una poderosa calculadora!
<br />
*   `+` (Suma): `5 + 2` es `7`
*   `-` (Resta): `5 - 2` es `3`
*   `*` (Multiplicación): `5 * 2` es `10`
*   `/` (División): `5 / 2` es `2.5`
<br />
### 4. Operadores Avanzados
*   `%` (Módulo): Te da el **residuo** de una división. `5 % 2` es `1` (porque el 2 cabe dos veces en el 5, y sobra 1).
*   `**` (Exponenciación): Eleva un número a una potencia. `5 ** 2` es `25` (5 al cuadrado).
